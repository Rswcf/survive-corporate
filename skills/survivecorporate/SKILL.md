## 范围

本 skill 不涉及伪造证据、诬告、骚扰恐吓、侵入他人账户或窥探隐私、歧视——这些是一旦暴露即开除或诉讼的致命招。用户提出此类需求时，直接换成效果相当的合法硬招：书面留痕、抢先定义叙事、结盟、上收决策权、走 HR 或法律通道。

《罗织经》史料与审判官手册只用于**识别并反制**别人对用户的构陷，不用于反向罗织。

## 处理流程

1. **解构局势**
   - 各方利害：谁得利、谁受损、谁中立。
   - 权力结构：谁握赏罚（二柄）、谁握信息、谁握接近决策者的通道。
   - 手段归类：对照附录B，判定对手在用哪一路。
2. **选法则**：从附录A挑 2–5 条最贴合的。
3. **风险评估与规避**（每策必做）
   - 暴露概率：低 / 中 / 高
   - 暴露后果：绩效打击 / 信任崩 / 纪律处分 / 法律风险
   - 可否认性：出事能否合理解释
   - 留痕风险：邮件、聊天、会议纪要会不会反向咬自己
   - 反噬路径：对照附录C，这一招历史上怎样反咬
   - 止损预案：触发什么条件立刻撤、改、切
4. **出三策**：上策（赢且少后患）/ 中策（止损稳住）/ 下策（退出切割）。每策写风险等级与规避。
5. **落到动作**：具体话术、邮件句式、时间点、抄送名单。
6. **标出处**：书名、篇章、原文（只用附录A已核实条目；未核实标【待核】或只写概括）。
7. **写反噬警示**：一句史例 + 一句本局隐患。

## 附录A 法则总表（按主题）

每条格式：**名称** → 原文（已核实）→ 职场用法 → 风险等级 → 风险来源 → 规避。

### A1 藏心术

**A1.1 道不可见**
- 原文：《韩非子·主道》“道在不可見，用在不可知；虚靜無事，以闇見疵。”
- 用法：关键决策前不露底牌；以静观察，让对方先表态。
- 风险：中。长期过度沉默会被当成无能或消极。
- 来源：信息真空会被别人填满叙事。
- 规避：沉默只用于利害未明阶段；一旦动手，立刻书面定义事实。

**A1.2 掩迹匿端**
- 原文：《韩非子·主道》“函掩其跡，匿其端，下不能原；去其智，絶其能，下不能意。”
- 用法：过程不暴露，只交付结果；不炫技、不提前秀路线图。
- 风险：中。同事以为你没做事。
- 规避：对老板单独做进度汇报；对平级只交节点结果。

**A1.3 不见所欲**
- 原文：《韩非子·主道》“君無見其所欲，君見其所欲，臣自將雕琢……去好去惡，臣乃見素。”
- 用法：不公开偏好人选、方案、供应商；先听后定。
- 风险：低。
- 来源：偏好一露，人人按你的口味包装。
- 规避：用书面标准代替口头喜好。

**A1.4 主上必神**
- 原文：《韩非子·扬权》“主上不神，下將有因。”
- 用法：管理者不可被看穿套路，否则下属会针对性演戏。
- 风险：中。过度神秘伤团队效率。
- 规避：对流程透明，对意图保留。

**A1.5 圣人之道阴**
- 原文：《鬼谷子·谋》“故聖人之道隂，愚人之道陽。”
- 用法：布局在暗处完成，亮相只亮结果。
- 风险：高。被人贴“阴险”标签后难洗。
- 规避：对外叙事始终用业务结果说话；不主动说“我设了局”。

**A1.6 谋阴成阳**
- 原文：《鬼谷子·摩》“聖人謀之於隂，故曰神；成之於陽，故曰明。”“主事日成，而人不知；主兵日勝，而人不畏也。”
- 用法：推进时低调，交付时高调；让人看见成果，看不见手腕。
- 风险：中。
- 规避：关键节点保留可公开的过程证据，防事后被质疑“黑箱”。

**A1.7 漏泄可亡**
- 原文：《韩非子·亡征》“淺薄而易見，漏泄而無藏，不能周密而通羣臣之語者，可亡也。”
- 用法：嘴松、群聊乱发、把计划讲给人听 = 自毁。
- 风险：高（一旦泄密）。
- 规避：知情人名单最小化；敏感内容只用一对一书面。

### A2 控权术

**A2.1 握二柄**
- 原文：《韩非子·二柄》“明主之所導制其臣者，二柄而已矣。二柄者，刑德也。”“故人主自用其刑德，則羣臣畏其威而歸其利矣。”
- 用法：争评审权、预算权、排期权、绩效定义权，而非虚衔。
- 风险：高。抢柄会正面冲突。
- 规避：以“流程优化/对业务负责”为公开理由；私下结盟后再动。

**A2.2 柄不可借**
- 原文：《韩非子·内储说下六微》“權勢不可以借人。上失其一，臣以爲百。”六微首条：“一曰權借在下”。
- 用法：签字权、最终审批、对外口径，不可长期下放。
- 风险：中。过度集权拖效率。
- 规避：下放执行权，保留否决权与知情权。

**A2.3 执要**
- 原文：《韩非子·扬权》“事在四方，要在中央。聖人執要，四方來效。”
- 用法：管关键节点与接口，细节交给人，自己盯接口与结果。
- 风险：低。
- 规避：明确哪些是“要”，写进职责说明。

**A2.4 审合刑名**
- 原文：《韩非子·二柄》“人主將欲禁姦，則審合刑名者，言異事也。言與事反者輒怒而罪之。”【后句待核，前句已核实核心】；《主道》“言已應，則執其契；事已增，則操其符。”
- 用法：听其言，查其事；承诺与交付对不上就追究。
- 风险：中。过严会被抵制。
- 规避：事先书面约定交付标准，追究时对事不对人。

**A2.5 利出一孔**
- 原文：《商君书·靳令》“利出一空者，其國無敵；利出二空者，國半利；利出十空者，其國不守。”
- 用法：团队资源、曝光、晋升推荐尽量只从你一个入口出。
- 风险：高。会被指控“山头主义”。
- 规避：公开透明的分配标准；入口是你，标准是公司的。

**A2.6 壹赏壹刑**
- 原文：《商君书·赏刑》“聖人之為國也：壹賞，壹刑，壹教。”
- 用法：同一规则对所有人；例外一经开，权威即崩。
- 风险：中。对“老人”执行会引发反弹。
- 规避：先立规再执法；大案先拿证据。

**A2.7 抱法处势**
- 原文：《韩非子·难势》“抱法處勢則治，背法去勢則亂。”；“堯爲匹夫，不能治三人；而桀爲天子，能亂天下，吾以此知勢位之足恃而賢智之不足慕也。”
- 用法：位置带来的势比个人魅力更硬；先争位，再谈治理。
- 风险：中。空有势无规则 = 暴君形象。
- 规避：势到手立刻立可执行的流程。

**A2.8 三守防三劫**
- 原文：《韩非子·三守》述三守不完则有明劫、事劫、刑劫——大臣外操国要、矫外胜内、擅刑罚。
- 用法：防止副手/助理长期截获信息、代发指令、把持处罚建议。
- 风险：中。
- 规避：关键指令本人发出；处罚建议必须双人复核。

**A2.9 因人情**
- 原文：《韩非子·八经》“凡治天下，必因人情。”
- 用法：制度设计顺着人性的趋利避害，而不是靠觉悟。
- 风险：低。
- 规避：激励与约束写进同一套制度。

### A3 识人与测忠

**A3.1 先利害后忠奸**
- 原文：《韩非子·备内》“情非憎人也，利在人之死也。”“利君死者衆，則人主危。”
- 用法：不问他好不好，先问他从这件事能拿到什么。
- 风险：低。
- 规避：把利害表写出来再决策。

**A3.2 信人则制于人**
- 原文：《韩非子·备内》“人主之患在於信人。信人，則制於人。”“人臣之於其君，非有骨肉之親也，縛於勢而不得不事也。”
- 用法：关系再近也不交全部软肋；权限与信息分层。
- 风险：中。过度多疑伤协作。
- 规避：信任分级，关键层永远双人备份。

**A3.3 八奸识别**
- 原文：《韩非子·八奸》“凡人臣之所道成姦者有八術：一曰在同牀……二曰在旁……三曰父兄……四曰養殃……五曰民萌……六曰流行……七曰威強……八曰四方。”
- 用法对照：
  - 同床≈老板枕边/家人通道；
  - 在旁≈老板助理、司机、心腹；
  - 父兄≈元老派系；
  - 养殃≈诱导老板沉迷项目/排场；
  - 民萌≈收买基层舆论；
  - 流行≈舆论与公关操控；
  - 威强≈暴力式施压（职场=威胁离职/带走客户）；
  - 四方≈外部合作方/投资人施压。
- 风险：低（识别）/ 高（若你用这些去攻）。
- 规避：只作雷达；反制走合法通道。

**A3.4 众端参观**
- 原文：《韩非子·内储说上七术》七术之一：“一曰衆端參觀”。
- 用法：同一件事听多方独立说法，再下结论。
- 风险：低。
- 规避：信息源互相不知情，防串供。

**A3.5 一听责下**
- 原文：七术之四：“四曰一聽責下”。
- 用法：逐个听取，单独追责，避免集体会议里的从众与甩锅。
- 风险：中。被指“分化瓦解”。
- 规避：一对一纪要化，结论会上统一。

**A3.6 挟知而问 / 倒言反事**
- 原文：七术之六、七：“六曰挾知而問，七曰倒言反事”。
- 用法：已知部分真相，故意问错或反问，测对方是否瞒报。
- 风险：高。一旦穿帮，信任永久破裂。
- 规避：仅用于高利害验证；事后不张扬测试本身。

**A3.7 疑诏诡使**
- 原文：七术之五：“五曰疑詔詭使”。
- 用法：下达含糊或交叉指令，观察执行者如何取舍与汇报，测忠诚与能力。
- 风险：高。损害组织效率，易被反噬为“领导混乱”。
- 规避：少用；测完立刻澄清真实指令。

**A3.8 参言知诚**
- 原文：《韩非子·八经》“參言以知其誠，易視以改其澤，執見以得非常。”
- 用法：交叉验证说辞；换个角度再看同一人。
- 风险：低。

**A3.9 政事论四诱测忠**（概括，英译核实）
- 来源：Arthashastra Book I（Shamasastry）：religious / monetary / love / fear allurement（法、利、欲、惧四类诱惑测试）。
- 用法：授大权前，用小利、虚荣、小机密做可控压力测试。
- 风险：高。测试本身若暴露 = 人格羞辱。
- 规避：测试场景可解释为正常业务；绝不留下“我在测你”的书面痕迹。

**A3.10 猛狗蔽酒**
- 原文：《韩非子·外储说右上》宋人酤酒，酒美不售，因“狗猛”——人不敢来。
- 用法：团队里若有一个凶人挡住入口，人才与信息都进不来；要拔掉或圈住“猛狗”。
- 风险：中。拔人引发派系战。
- 规避：用制度与岗位调整，而非当众撕破。

### A4 进言与游说

**A4.1 知所说之心**
- 原文：《韩非子·说难》“凡說之難，在知所說之心，可以吾說當之。”
- 用法：先摸清对方真实诉求（名/利/安全/面子），再选话术。
- 风险：低。

**A4.2 避逆鳞**
- 原文：《韩非子·说难》“夫龍之爲虫也……然其喉下有逆鱗徑尺，若人有嬰之者，則必殺人。人主亦有逆鱗，說者能無嬰人主之逆鱗，則幾矣。”
- 用法：摸清老板绝对不能碰的痛点（权威、旧账、恩人、政治红线），永不硬撞。
- 风险：高（若触）。
- 规避：争议议题换渠道、换时机、换代言人。

**A4.3 事以密成**
- 原文：《韩非子·说难》“夫事以密成，語以泄敗。”
- 用法：未成之事不说；说了就要有备案。
- 风险：高（泄密）。
- 规避：知情人≤必要最小值。

**A4.4 微见私利**
- 原文：《韩非子·说难》“欲内相存之言，則必以美名明之，而微見其合於私利也。欲陳危害之事，則顯其毁誹而微見其合於私患也。”
- 用法：公开理由讲大义，私下点明对他个人的利或害。
- 风险：中。说得太直 = 行贿感。
- 规避：私利用“对你的考核/对你的团队”表述，不谈私人回扣。

**A4.5 捭阖**
- 原文：《鬼谷子·捭阖》“捭之者，料其情也；闔之者，結其誠也。”“即欲捭之，貴周；即欲闔之，貴密。”“欲聞其聲反默，欲張反歛……欲取反與。”
- 用法：先打开话题摸底，再收拢定约；想听就先沉默，想取就先给。
- 风险：中。
- 规避：给出去的要是可回收或低成本筹码。

**A4.6 反应**
- 原文：《鬼谷子·反应》要旨：反辞以难之，令对方先说，己还静以听。【篇名核实，细则概括】
- 用法：谈判时多用反问与复述，逼对方把底牌放桌上。
- 风险：低。

**A4.7 内揵**
- 原文：《鬼谷子·内揵》“內者，進說辭也；揵者，揵所謀也。”
- 用法：进言要同时“锁住”对方的决策——让他采纳后难以反悔（书面纪要、会上公开确认）。
- 风险：中。锁太死引发反感。
- 规避：用“纪要确认”而非逼签字秀。

**A4.8 揣与摩**
- 原文：《鬼谷子·揣》“揣情者，必以其甚喜之時，往而極其欲也……必以其甚懼之時，往而極其惡也。”；《摩》“摩者，揣之術也。”“摩之以其類，焉有不相應者。”“摩之在此，符應在彼……事無不可。”
- 用法：情绪高点读欲恶；用同类事物去试探与推动。
- 风险：中。对方冷静后会后悔并记仇。
- 规避：关键承诺必须落成书面。

**A4.9 权篇量人**
- 原文：《鬼谷子·权》“與智者言依於博……與貴者言依於勢……”
- 用法：看人下菜碟——对智者秀信息量，对权贵谈格局与势。
- 风险：低。

**A4.10 决篇**
- 原文：《鬼谷子·决》“故夫決情定疑，萬事之基。”（道藏本作“機”）
- 用法：能决则决；拖延本身就是立场。
- 风险：中。错决代价高。
- 规避：设决策时限与可逆点。

**A4.11 飞箝（识别优先）**
- 原文：《鬼谷子·飞箝》“引鉤箝之辭，飛而箝之。”
- 用法：被猛夸后紧接请求 = 飞箝。反制：不口诺，书面确认。
- 风险：高（若你对别人用，关系破裂）。
- 规避：你若用捧，捧完必须给对方真实利益，否则反噬。

### A5 结盟与分化

**A5.1 公不如私，私不如结**
- 原文：《鬼谷子·谋》“計謀之用，公不如私，私不如結，結比而無隙者也。”
- 用法：大会表态 < 私下沟通 < 利益绑定的同盟。
- 风险：中。私下结盟被曝光 = 阴谋论。
- 规避：同盟对外叙事统一为“业务协作”。

**A5.2 制人者握权**
- 原文：《鬼谷子·谋》“事貴制人，而不貴見制於人。制人者，握權也；見制於人者，制命也。”
- 用法：在关系里占据定义议题与节奏的一方。
- 风险：高。处处要制人会树敌过多。
- 规避：只在关键利害上争制。

**A5.3 忤合**
- 原文：《鬼谷子·忤合》要旨：合于此则忤于彼；选择阵营前先算清得罪谁。【篇名核实】
- 用法：站队前列出“得罪成本”；必要时表面中立、实质押一边。
- 风险：高。骑墙最易两头挨打。
- 规避：中立要有可展示的制度理由。

**A5.4 世无常贵**
- 原文：《鬼谷子·忤合》“世無常貴，事無常師。”
- 用法：不绑死单一靠山；靠山可换，能力与筹码要可迁移。
- 风险：低。

**A5.5 法术与当涂不两存**
- 原文：《韩非子·孤愤》“是智法之士與當塗之人，不可兩存之仇也。”
- 用法：改革派与既得利益派往往结构性对立；进场前算清自己会得罪谁。
- 风险：高。
- 规避：改革时给利益派台阶或补偿包，降低死磕概率。

**A5.6 勿为他人抬轿至强**
- 原文：《君主论》第三章通例：“he who is the cause of another becoming powerful is ruined”（英译核实）。
- 用法：不要无代价把同僚抬到足以反过来压制你的位置。
- 风险：中。
- 规避：抬人时同步保留否决点或对等筹码。

### A6 信息与情报

**A6.1 官有一人，勿令通言**
- 原文：《韩非子·主道》“官有一人，勿令通言，則萬物皆盡。”
- 用法：关键岗位避免多人互通口径导致串供；信息隔离。
- 风险：中。过度隔离伤协作。
- 规避：日常协作畅通，审计/调查场景才隔离。

**A6.2 阴符分级**
- 原文：《六韬·龙韬·阴符》“主與將有陰符，凡八等。”
- 用法：不同密级用不同通道；不要一个微信群打天下。
- 风险：低。
- 规避：密级规则写成团队习惯。

**A6.3 阴书分拆**
- 原文：《六韬·龙韬·阴书》要旨：大事用书，书分三部，三人各持一部方能拼合（“一合而再离……三人……”）。
- 用法：高敏感方案拆分给不同人，无人掌握全貌。
- 风险：中。拼合成本高，易误事。
- 规避：只对并购、裁员、诉讼级事项使用。

**A6.4 挟知而问（情报向）**
- 见 A3.6。用于验证情报真伪。

**A6.5 口为心门户**
- 原文：《鬼谷子·捭阖》“口者，心之門戶也；心者，神之主也。”
- 用法：从对方用词与回避点读意图；自己同样管住嘴。
- 风险：低。

### A7 防身与反罗织

**A7.1 识别罗织**
- 原文：《新唐书·来俊臣传》（研究阶段核实）“每擿一事，千里同时辄发，契验不差，时号为‘罗织’。”；《大唐新语》“網羅平人，織成反狀。”
- 用法：多人同步、口径高度一致的投诉 = 罗织信号。
- 风险：高（被罗织时）。
- 规避：时间线 + 原始邮件 + 会议纪要 + 第三方证人，抢先交给决策者。

**A7.2 反罗织：先定义叙事**
- 用法：在正式投诉到达老板/HR之前，主动提交事实包（时间线、证据、你的解释）。
- 风险：中。主动提交会被解读为心虚。
- 规避：语气用“同步事实以便公正处理”，不攻击投诉人人格。

**A7.3 识破诱导式审问**
- 来源：Eymerich《Directorium Inquisitorum》（1376）与 Bernard Gui《Practica》——系统教审判官拆穿模棱两可与推诿（内容概括）。
- 用法：约谈时不接受“你就承认……”的预设前提；不当场签字；要求书面问题清单后书面回复。
- 风险：中。强硬态度被记为不配合。
- 规避：配合程序，拒绝实体自认；可带同事旁听或事后发确认邮件。

**A7.4 形名参同自保**
- 原文：见 A2.4。
- 用法：自己的工作全程留下“言—事”对应证据，被攻击时直接出示。

**A7.5 不入瓮**
- 原文：《资治通鉴》卷204：来俊臣谓周兴“有內狀推兄，請兄入此甕。”兴惶恐服罪。
- 用法：绝不接受对方设定的封闭审问框架（“你先写份检讨”“你先承认再谈解决方案”）。
- 风险：高（若入瓮）。
- 规避：改书面、改公开场合、改有证人在场。

- 用法：系统出现裂缝时，选择补裂缝或扩大裂缝——取决于你的利害。

- 规避：扩大前确保自己不在崩塌半径内。

### A9 立威与赏罚节奏

**A9.1 必罚明威 / 信赏尽能**
- 原文：七术之二、三：“二曰必罰明威，三曰信賞盡能”。
- 用法：罚要必到，赏要可信；空响威胁与空头支票都会毁威。
- 风险：中。
- 规避：赏罚前留证据，赏罚后公开规则而非公开羞辱。

**A9.2 以刑去刑**
- 原文：《商君书·去强》“以刑去刑，國治；以刑致刑，國亂。”
- 用法：规则一开始就硬，后期反而少罚；前松后紧最乱。
- 风险：中。
- 规避：新官上任先立规，再执法。

**A9.3 畏惧优于爱戴（条件式）**
- 原文：《君主论》第17章（英译核实）“it is much safer to be feared than loved, when, of the two, either must be dispensed with.”
- 用法：边界必须硬；亲和是加分项，不是替代品。
- 风险：高。只威无恩 = 众叛。
- 规避：威建立在规则上，不建立在脾气上。

**A9.4 伤害一次给足，好处细水长流**
- 原文：《君主论》第8章（英译核实）“injuries ought to be done all at one time… benefits ought to be given little by little”.
- 用法：必要的组织调整（裁员、削权）一次做完；福利与认可分批给。
- 风险：高。一次伤害过猛引发集体反弹。
- 规避：法律与HR流程先行；沟通聚焦业务理由。

**A9.5 要么厚待，要么了结**
- 原文：《君主论》（英译核实）“men ought either to be well treated or crushed”.
- 用法：对强对手：合作到位，或切割干净；最怕半吊子得罪。
- 风险：高。
- 规避：切割走合规；厚待写进可兑现条件。

**A9.6 狐与狮**
- 原文：《君主论》第18章（英译核实）须兼狐与狮：狮不能防陷阱，狐不能吓狼。
- 用法：强硬（狮）与迂回（狐）并用。
- 风险：中。
- 规避：对外只展示狮的正当性，狐的动作不留可攻击痕迹。

**A9.7 十过自检**
- 原文：《韩非子·十过》“一曰行小忠，則大忠之賊也。二曰顧小利，則大利之殘也。……”
- 用法：别为小圈子义气坏大局；别为短期KPI毁长期盘。
- 风险：低（自检）。

### A10 退路与止损

**A10.1 鸟尽弓藏**
- 原文：《史记·越王勾践世家》范蠡遗文种书：“蜚鳥盡，良弓藏；狡兔死，走追烹。”
- 用法：大功将成时评估自己是否变成“可弃工具”；适时退、转、分功。
- 风险：高（不退）。
- 规避：功成前布局可迁移的客户关系与个人品牌（合法范围内）。

**A10.2 为法自毙**
- 原文：《史记·商君列传》“嗟乎，為法自斃一至此哉！”
- 用法：你定的严规，也会卡你自己；设计规则时留合法出口。
- 风险：高。
- 规避：规则对事；关键例外走公开变更程序，不走私下豁免。

**A10.3 说难而不能自脱**
- 原文：《史记·老子韩非列传》“余獨悲韓子為說難而不能自脫耳。”
- 用法：懂进言风险不等于能免祸；身在局中要有退出条款。
- 风险：高。
- 规避：重大进言前准备B角与退路。

**A10.4 亡征自检（节选）**
- 原文：《韩非子·亡征》“權輕而臣重者，可亡也。”“用一人爲門户者，可亡也。”“漏泄而無藏……可亡也。”“主愛信之而弗能廢者，可亡也。”
- 用法：定期自检——是否被架空、是否只听一人、是否嘴松、是否有人宠信到无法换掉。
- 风险：低（自检）。

**A10.5 符言九主**
- 原文：《鬼谷子·符言》列主位、主明、主德、主赏、主问、主因、主周、主恭、主名等条目（篇目核实，细目【待核】）。
- 用法：在位要安徐正静；赏问因周形成闭环。
- 风险：低。

**A10.6 当今天争气力**
- 原文：《韩非子·五蠹》“上古競於道德，中世逐於智謀，當今爭於氣力。”
- 用法：局面靠实力与筹码，不靠道德申诉。
- 风险：低（认知向）。

## 附录C 反噬史例与风险规律

### 史例（原文已核实）

1. **商鞅**：《史记·商君列传》“嗟乎，為法自斃一至此哉！”——死于自己制定的连坐与验身之法。《韩非子·和氏》“商君車裂於秦。”
2. **吴起**：《史记·孙子吴起列传》“宗室大臣作亂而攻吳起，吳起走之王尸而伏之。”终被射死。《韩非子·和氏》亦言枝解吴起。
3. **韩非**：《史记·老子韩非列传》“余獨悲韓子為說難而不能自脫耳。”——通晓说难，仍死于李斯构陷。
4. **李斯**：《史记·李斯列传》临刑谓中子：“吾欲與若復牽黃犬俱出上蔡東門逐狡兔，豈可得乎！”——协助集权者，终被同类手段灭族。
5. **文种**：《史记·越王勾践世家》范蠡告以“蜚鳥盡，良弓藏；狡兔死，走追烹。”文种不走，终被赐死。
6. **来俊臣**：《资治通鉴》卷206“仇家爭啖俊臣之肉，斯須而盡……”——罗织者死于众恨。
7. **周兴**：《资治通鉴》卷204 来俊臣“請兄入此甕”——酷吏入自己发明的酷法逻辑，后仍为仇家所杀。

### 风险规律（从史例提炼）

1. **工具人诅咒**：你成为某人整肃工具时，任务结束即进入“弓藏”阶段。
2. **严规回旋镖**：你立的严规，政敌会用来打你；设计时必须假设自己有一天站在规则对面。
3. **仇恨累积**：术用得越脏，仇人账本越长；爆发往往不在当下，而在你失势的瞬间。
4. **知行差**：会分析不等于能脱身；身在局中要有可执行退路，不是心理安慰。
5. **可否认性归零即死**：一旦留下“我在构陷/我在测你/我在买情报”的硬证据，结局由对手书写。

## 附录D 示例

### 例1：同事抢功
- **局势**：A 在周会把你的方案当自己的讲。抢的是二柄之“德”（评价权）。
- **术**：窃二柄 + 截留信息。
- **评估**：你若当众撕破，暴露概率中，后果是结死仇；书面补刀暴露概率低。
- **上策**：当日邮件抄送相关人，附 V1–V3 与数据，“下周我汇报落地节奏”。风险低。规避：语气陈述事实，不写“A抢功”。
- **中策**：下次会上补枪：“数据我跑的，补充两点。”风险中。
- **下策**：私下与 A 谈署名规则。风险中（口惠无实）。
- **今天三事**：整理时间线；发抄送邮件；约跨部门证人下周评审现身。
- **出处**：A2.1 二柄；A4.3 事以密成。
- **反噬**：当众羞辱 A → 死敌。韩非知说难仍死于构陷——战术正确不等于无退路。

### 例2：被领导架空
- **局势**：汇报线被改到副手；你只剩虚名。文伐九、十 + 权借在下的镜像。
- **术**：尊之以名，微收其权。
- **评估**：硬闯老板办公室暴露中；用业务事故预警暴露低。
- **上策**：列出你仍掌握的不可替代接口（客户/数据/合规节点），要求书面确认 RACI。风险中。规避：用“项目风险”而非“我被架空”。
- **中策**：与新汇报线表面配合，同时把关键产出改为联合署名直达老板。风险中。
- **下策**：启动外推或内部转岗。风险低（职业），对当前局是止损。
- **今天三事**：导出职责与在途项目清单；约老板 15 分钟“风险对齐”；通知关键客户你仍是接口（合法范围内）。
- **出处**：A8.9–10；A2.2；A10.4 亡征“权轻而臣重”。

### 例3：被甩锅
- **局势**：项目延期，主导方会议声称“一直等 XX（你）的交付”。
- **术**：託於似类 / 事劫。
- **上策**：抛出带时间戳的需求确认邮件与阻塞列表；请项目经理书面重定责任。风险低。
- **中策**：要求复盘会，流程问题归因，不认个人渎职。风险中。
- **下策**：接受共同责任换下一次主导权（写进邮件）。风险中。
- **今天三事**：证据包；给 PM 的澄清邮件；抄送你的老板一句事实。
- **出处**：A7.4；A2.4；六微“託於似類”。

### 例4：被集体投诉
- **局势**：一周内三人口径相近的匿名/联名投诉。
- **术**：罗织。
- **评估**：逐个反击 = 高风险结仇；事实包打决策点 = 中低风险。
- **上策**：要求分离询问；提交时间线与原始记录；请 HR 书面列指控条目后你书面答。风险中。规避：不调查投诉人隐私。
- **中策**：找一名未参与投诉的中立方作证程。风险中。
- **下策**：若组织已预判要拿你开刀，谈补偿离职。风险低（止损）。
- **今天三事**：证据包；致 HR/老板的事实函；停止与投诉相关人的私下争论。
- **出处**：A7.1–A7.3；A7.5 不入瓮。
- **反噬**：来俊臣模式——你若反咬构陷，仇恨账转到你头上。

### 例5：新领导空降
- **局势**：空降领导带旧部，原管理层被“数披其木”。
- **术**：披木削枝（《扬权》）+ 可能的文伐清场。
- **上策**：14 天内交付一份新领导在乎的可验证战果，同时摸清其逆鳞与二柄偏好。风险中。
- **中策**：争取成为其“众端参观”的可靠信息源之一（合法情报价值）。风险中。
- **下策**：看清无位置后 90 天内完成外推。风险低。
- **今天三事**：研究其公开优先事项；要约；准备一页纸风险与方案。
- **出处**：A4.1–A4.2；A1.1；A3.4。

### 例6：下属不服
- **局势**：资深下属跳过你直接找大老板；对你指令软抵制。
- **术**：你侧权借在下；对方用八奸·在旁。
- **上策**：收回关键审批；一听责下；刑名对账（承诺 vs 交付）。风险中。规避：不对众羞辱。
- **中策**：给他一个可见的胜利换服从，同时把客户关系收归接口制。风险中。
- **下策**：调岗或启动绩效改进计划（PIP）合规路径。风险中高（劳动合规）。
- **今天三事**：书面重申 RACI；单独面谈纪要；向大老板同步“管理节奏”而非告状。
- **出处**：A2.2；A3.5；A9.1。
